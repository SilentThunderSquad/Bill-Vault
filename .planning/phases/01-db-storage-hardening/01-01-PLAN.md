<action>
Create a migration `20240420000001_rls_policies.sql` that enables RLS on `profiles` and `bills` tables and implements strict owner-only policies:
```sql
ALTER TABLE profiles ENABLE ROW LEVEL SECURITY;
ALTER TABLE bills ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Users can only access their own profile" ON profiles
    FOR ALL TO authenticated USING (auth.uid() = id);

CREATE POLICY "Users can only access their own bills" ON bills
    FOR ALL TO authenticated USING (auth.uid() = user_id) WITH CHECK (auth.uid() = user_id);
```
</action>
<acceptance_criteria>
- Migration file exists with `ALTER TABLE ... ENABLE ROW LEVEL SECURITY`.
- Policies use `auth.uid()` to verify ownership.
- Tests confirm a user cannot read another user's bill.
</acceptance_criteria>
</task>
