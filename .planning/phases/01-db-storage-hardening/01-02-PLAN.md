# Plan 01-02: Storage Hardening & Malware Scanning

Secure the file storage layer and implement automated malware scanning for all uploads.

## Tasks

<task>
<read_first>
- supabase/migrations/20240420000001_rls_policies.sql
</read_first>
<action>
Create a migration `20240420000003_storage_policies.sql` to secure the `bills` storage bucket:
1. Create the `bills` bucket (private).
2. Apply RLS to `storage.objects` for hierarchical access:
```sql
CREATE POLICY "Users can only access their own folder in bills bucket" ON storage.objects
    FOR ALL TO authenticated
    USING (bucket_id = 'bills' AND (storage.foldername(name))[1] = auth.uid()::text);
```
</action>
<acceptance_criteria>
- `bills` bucket exists and is not public.
- Policy restricts access based on the `user_id` prefix in the file path.
- Tests confirm `userA` cannot download `userB/bill.pdf`.
</acceptance_criteria>
</task>
